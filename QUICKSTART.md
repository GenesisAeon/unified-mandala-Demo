# Quickstart (5–10 min)

1) Setup  
```bash
pnpm install
pnpm dev
# oder:
docker compose up
```

2. Einstieg

* `index.html` öffnen (Landing-Page)
* `HANDBUCH.md` Abschnitt „Erste 30 Minuten“

3. Erstes Sigil laden

* Beispiel-Sigil (YAML/JSON) in die UI laden (z. B. Übergabe/Anchor)

4. Report ansehen (falls Runner konfiguriert)

* `runs/<timestamp>/report.html`

5. Guardrails (optional)

```bash
pnpm guardrails:check    # CREP-Ranges & Sigillin-Schema
```
