# Hydro Watch

Lightweight adapters for water resilience metrics.

## Metrics
- **HVI (σ/μ):** Measures hydrological variability relative to the mean. High values imply difficult planning.
- **BLR (Buffer-to-Load):** Storage divided by demand. Ratios below 1 indicate deficits (🧯).
- **Teleconnection-Watch:** Detects remote climate drivers (ENSO/IOD/NAO). Strong influence triggers 🛰️.

## Sigils
- 🟢 stable
- 🟠 watch
- 🔴 critical
- 🧯 deficit
- 🛰️ strong teleconnection
