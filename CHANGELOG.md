- Initial v1.0.0 release as part of the GenesisAeon ecosystem-wide 1.0.0
  milestone.

- Dual-licensing: GPL-3.0-or-later (code) + CC BY 4.0 (documentation).

- Project metadata normalized: `pyproject.toml` added (version, license,
  authors, `requires-python`); `package.json` `license` field set to
  `GPL-3.0-or-later`.
